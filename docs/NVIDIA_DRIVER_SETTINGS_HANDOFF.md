# 게임마다 켜기: PC 확인 안내

이 문서는 ‘게임마다 켜기’ 화면이 실제 NVIDIA 드라이버에서 의도대로 동작하는지 PC에서 확인하는
순서입니다. 저장소의 테스트는 메모리 안의 가짜 드라이버 설정과 NVAPI 대역으로만 돌기 때문에,
실제 `nvapi64.dll` 호출은 이 확인으로 처음 증명됩니다. 드라이버 설정을 바꾸는 일이라 펌웨어나
메인보드와는 관계가 없고, 언제든 화면의 백업으로 되돌릴 수 있습니다.

## 준비

- 이 변경이 병합된 `master` 커밋의 Windows 사전 배포판(GitHub Releases의 pre-release)을 받습니다.
- 드라이버 616.64(또는 그 이후)인 PC에서 앱을 **관리자 권한으로** 실행합니다.
- 비교용으로 NVIDIA 앱이나 NVIDIA Profile Inspector를 열어 둘 수 있으면 좋습니다. 앱은 이 둘에
  기대지 않고, 값을 맞게 썼는지 눈으로 대조하는 데만 씁니다.

## 확인 순서

1. **목록 읽기:** 홈에서 ‘게임마다 켜기’를 엽니다. ‘드라이버 616.64에 등록된 게임 N개’가 나오는지,
   N이 수천 개인지, 화면이 뜰 때까지 몇 초 걸리는지 적어 둡니다.
2. **NVIDIA가 켜 둔 게임:** 검색에 `cyberpunk`(또는 NVIDIA가 Resizable BAR를 켜 둔 다른 게임)를
   입력합니다. 스위치가 켜져 있고 설명이 ‘NVIDIA 기본값’인지 봅니다.
3. **한 게임 켜기:** 꺼져 있는 게임 하나를 켭니다. 스위치가 잠시 돌다가 켜진 채 남는지,
   ‘이 PC에서 바꾼 게임’에 그 게임이 나오는지 확인합니다. ‘NVIDIA 설정 백업’을 펼쳐 백업 파일
   경로가 보이는지도 확인합니다(`%LOCALAPPDATA%\io.github.nvstrapsrebar.desktop\nvidia-driver-settings\backups`).
4. **값 대조:** NVIDIA Profile Inspector에서 같은 게임 프로필을 열어 아래 값이 들어갔는지 봅니다.
   NVIDIA 앱을 쓴다면 그 게임의 Resizable BAR가 ‘켜기’로 나오는지 봅니다.

   | 설정 | 기대값 |
   | --- | --- |
   | `0x000BFA21` (NVIDIA 앱 Resizable BAR, Profile Inspector에서는 rBAR - Enable v2) | `0x00000002` |
   | `0x000F00BA` rBAR - Enable | `0x00000001` |
   | `0x000F00BB` rBAR - Options | 프로필에 원래 값이 없었다면 `0x00000001` |
   | `0x000F00FF` rBAR - Size Limit | 프로필에 원래 값이 없었다면 `0x0000000040000000` (1 GiB) |

5. **게임에서 확인:** 그 게임을 실행해 평소처럼 동작하는지 봅니다. 이미 켜져 있던 게임은 다시
   실행해야 바뀐 값을 읽습니다.
6. **다시 끄기:** 같은 게임을 끕니다. 원래 꺼져 있던 게임이면 Profile Inspector에서 위 값들이
   사라지고(기본값으로 돌아가고), 화면 설명에서 ‘이 PC에서 바꿈’이 빠지는지 봅니다.
7. **NVIDIA가 켜 둔 게임 끄기:** 2번의 게임을 끕니다. Profile Inspector에서 `0x000BFA21`이
   `0x00000000`, rBAR - Enable이 `0x00000000`으로 들어갔는지 봅니다. 확인 뒤 다시 켜거나 9번으로
   되돌립니다.
8. **모든 게임:** ‘모든 게임’ 스위치를 켭니다. 동의 창이 뜨는지, ‘모두 켜기’를 누른 뒤 아무
   게임이나 검색했을 때 설명이 ‘‘모든 게임’ 설정’으로 켜져 보이는지 확인합니다. Profile
   Inspector의 `_GLOBAL_DRIVER_PROFILE (Base Profile)`에 4번 표의 값이 들어갔는지 봅니다. 확인했으면
   다시 끕니다(끌 때는 창이 뜨지 않습니다).
9. **되돌리기:** ‘NVIDIA 설정 백업’에서 ‘이 백업으로 되돌리기’를 누르고 확인합니다. 3~8번에서
   바꾼 값이 모두 처음 상태로 돌아가는지 Profile Inspector로 봅니다.
10. **관리자 권한 없이:** 앱을 일반 권한으로 열어 이 화면에 들어갑니다. 목록이 읽히는지,
    ‘관리자 권한으로 다시 여세요’ 카드와 함께 스위치가 잠기는지 봅니다. 목록 읽기부터 실패하면 그
    문구를 적어 둡니다.

## 진단 기록

앱은 드라이버 설정 명령을 실행할 때마다 아래 파일에 한 줄씩 남깁니다. 결과를 알려 주실 때 이
파일을 함께 보내 주시면 됩니다. 화면의 ‘백업과 진단 기록’을 펼치면 같은 경로가 보이고, 오류
안내에도 이 경로가 붙습니다.

- `%LOCALAPPDATA%\io.github.nvstrapsrebar.desktop\logs\driver-settings.log`: 명령의 시작과 끝,
  걸린 시간, 실패한 NVAPI 호출과 그 인자, 쓴 값과 지운 값, 바꾸기 전 값과 다시 읽은 값(설정마다
  값, 위치, NVIDIA 기본값 여부), 읽지 못해 목록에서 뺀 프로필, 건너뛴 백업과 그 이유. 2 MiB를
  넘으면 `.log.1`로 넘기고 새로 씁니다.
- `%LOCALAPPDATA%\io.github.nvstrapsrebar.desktop\logs\panic.log`: 앱이 예기치 않게 꺼졌을 때의
  위치와 메시지. 배포판은 패닉 시 바로 종료하므로 이 파일이 유일한 흔적입니다.

## 알려 주실 결과

단계마다 된 것과 안 된 것을 적어 주시면 됩니다. 특히 다음 네 가지가 다음 수정에 필요합니다.

- 1번의 게임 수와 걸린 시간.
- 4번과 7번에서 Profile Inspector나 NVIDIA 앱에 보인 실제 값.
- 화면에 뜬 오류 문구(아래 줄의 영어 원문까지)와 그때 누른 스위치.
- 616.64에서 `0x000BFA21`만 바꿔도 NVIDIA 앱 표시가 바뀌는지, 기존 rBAR 값과 함께 바꿔야 하는지에
  대한 관찰.

## 문제가 생기면

- 화면의 ‘이 백업으로 되돌리기’가 첫 변경 직전의 드라이버 설정 전체를 되돌립니다.
- 앱이 열리지 않는다면 NVIDIA Profile Inspector에서 위 백업 파일과 같은 시점의 설정으로 돌리거나,
  해당 게임 프로필에서 위 네 값을 지웁니다.

## 이 확인으로 증명되는 것과 남는 것

- 증명: NVAPI 함수 번호와 구조체 크기가 실제 드라이버와 맞는지, 관리자 권한이 필요한지, 드라이버가
  쓴 값을 다시 돌려주는지, 백업과 되돌리기가 실제로 동작하는지.
- 남는 것: 게임 안에서 Resizable BAR가 실제로 쓰였는지는 드라이버가 보고하지 않습니다. 체감
  성능이나 다른 도구로 판단합니다.
