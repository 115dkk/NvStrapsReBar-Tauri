# NvStrapsReBar 1.0.1

A dependency security update. The app and the UEFI driver behave exactly as in 1.0.0; the UEFI
driver (`NvStrapsReBar.ffs`) is built from unchanged code, so a board already flashed with 1.0.0
does not need to be flashed again.

## Fixed advisories

The app is rebuilt against patched versions of two Rust crates that the Tauri framework pulls in.
The app's own code calls neither crate.

- `time` 0.3.45 to 0.3.47: stack exhaustion when parsing hostile RFC 2822 dates
  ([GHSA-r6v5-fh4h-64xc](https://github.com/advisories/GHSA-r6v5-fh4h-64xc)).
- `serde_with` 3.17.0 to 3.21.0: a panic when serializing an empty entry through `KeyValueMap`
  ([GHSA-7gcf-g7xr-8hxj](https://github.com/advisories/GHSA-7gcf-g7xr-8hxj)).

Three development tools are updated as well. None of them ships in the downloads.

- `vitest` and `@vitest/mocker` 4.1.10 to 4.1.11: a path traversal through redirect mocks on a
  reachable dev server ([GHSA-82fw-gwwq-j7x9](https://github.com/advisories/GHSA-82fw-gwwq-j7x9)).
- `source-map-js` 1.2.1 to 1.2.2: an event-loop stall on crafted indexed source maps
  ([GHSA-68fv-2mgg-jv7q](https://github.com/advisories/GHSA-68fv-2mgg-jv7q)).

## Still open

`glib` 0.18 has an unsound iterator
([GHSA-wrw7-89jp-8q8g](https://github.com/advisories/GHSA-wrw7-89jp-8q8g)). It is part of the GTK
3 stack that Tauri uses on Linux only, so the Windows app does not contain it. The fix is in glib
0.20, and every Tauri 2 release still requires GTK 3 bindings 0.18, so it stays until Tauri moves on.

## Downloads

The same three files as 1.0.0: the portable zip, the installer and `SHA256SUMS.txt`.

# NvStrapsReBar 1.0.1 (한국어)

의존성 보안 업데이트입니다. 앱과 UEFI 드라이버의 동작은 1.0.0과 같습니다. UEFI
드라이버(`NvStrapsReBar.ffs`)의 코드는 바뀌지 않았으므로, 1.0.0으로 이미 플래시한 보드는 다시
플래시할 필요가 없습니다.

## 고친 보안 권고

Tauri 프레임워크가 끌어오는 Rust 크레이트 두 개를 수정된 버전으로 올려 앱을 다시 빌드했습니다.
앱 자체의 코드는 두 크레이트 모두 직접 호출하지 않습니다.

- `time` 0.3.45에서 0.3.47로: 악의적으로 만든 RFC 2822 날짜를 해석할 때 스택이 고갈되는 문제
  ([GHSA-r6v5-fh4h-64xc](https://github.com/advisories/GHSA-r6v5-fh4h-64xc)).
- `serde_with` 3.17.0에서 3.21.0으로: `KeyValueMap`으로 빈 항목을 직렬화할 때 패닉이 나는 문제
  ([GHSA-7gcf-g7xr-8hxj](https://github.com/advisories/GHSA-7gcf-g7xr-8hxj)).

개발 도구 세 개도 함께 올렸습니다. 이 도구들은 배포 파일에 들어가지 않습니다.

- `vitest`, `@vitest/mocker` 4.1.10에서 4.1.11로: 외부에서 접근할 수 있는 개발 서버에서 리다이렉트
  목(mock)을 통해 경로를 벗어난 파일을 읽을 수 있는 문제
  ([GHSA-82fw-gwwq-j7x9](https://github.com/advisories/GHSA-82fw-gwwq-j7x9)).
- `source-map-js` 1.2.1에서 1.2.2로: 조작된 인덱스 소스맵이 이벤트 루프를 오래 붙잡는 문제
  ([GHSA-68fv-2mgg-jv7q](https://github.com/advisories/GHSA-68fv-2mgg-jv7q)).

## 남아 있는 권고

`glib` 0.18에는 안전하지 않은 반복자 구현이 있습니다
([GHSA-wrw7-89jp-8q8g](https://github.com/advisories/GHSA-wrw7-89jp-8q8g)). 이 크레이트는 Tauri가
Linux에서만 쓰는 GTK 3 계열이라 Windows 앱에는 들어 있지 않습니다. 수정은 glib 0.20에 있는데
Tauri 2의 모든 릴리스가 아직 GTK 3 바인딩 0.18을 요구하므로, Tauri가 이를 바꿀 때까지 남습니다.
