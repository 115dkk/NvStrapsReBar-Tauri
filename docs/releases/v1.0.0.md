# NvStrapsReBar 1.0.0

The first stable release. It turns on Resizable BAR for NVIDIA Turing GPUs (GTX 1600 and RTX 2000)
on motherboards whose BIOS never offered it, with a stable-Rust UEFI driver and a Windows app that
prepares the BIOS image and edits the driver's settings.

## Verified on hardware

- MSI MAG B660 TOMAHAWK WIFI DDR5 (MS-7D41, BIOS 7D41vAO) with an RTX 2060 12GB: the image prepared
  with this project's injector was accepted by MSI's M-FLASH, the driver booted, the app configured
  it, and the app and GPU-Z both reported a 16 GiB BAR1 afterwards
  ([report](https://github.com/115dkk/NvStrapsReBar-Tauri/issues/39)).
- Per-game switches were verified against the NVIDIA driver (RTX 2080 SUPER, driver 616.64) on the
  maintainer's PC, including the undo of every value the app wrote.

Every other board is still its own trial. Confirm your recovery route before flashing.

Special thanks to @lucianocerantonio2 for that first physical-board test: the flash, the
configuration, and a report with hashes and screenshots that let the rest of us trust the result.

## What is in the box

- `NvStrapsReBar-windows-x64.zip`: the portable app (`NvStrapsReBar.exe`) with the UEFI driver it
  injects (`NvStrapsReBar.ffs`). Keep the two files together.
- `NvStrapsReBar-windows-x64-setup.exe`: the same two files as an installer with Start menu and
  optional desktop shortcuts.
- `SHA256SUMS.txt`: checksums of both downloads.

Requires Windows x64 with WebView2 and an administrator account for the UEFI variable. The NVIDIA
driver's per-game settings exist only on Windows, and macOS has no NVIDIA driver for Turing GPUs,
so there is no Linux or macOS app.

## Features

- Guided installation in four stages: prepare the BIOS image and a USB package with the untouched
  original, install it with the vendor's own tool, turn the expansion on, and read the resulting
  BAR size back from the NVIDIA driver.
- BAR Settings for expansion on/off, per-GPU sizes and exclusions, a motherboard-side BAR limit,
  and a settings file for hardware changes.
- Per-game Resizable BAR through the driver's own settings database: one switch per game, an
  all-games switch with consent, a record of every value changed, and an undo that touches nothing
  else, even after a driver update.
- Safety guards in the driver: it sits out a boot when BIOS setup settings change and turns itself
  off after a CMOS reset.
- Legacy-board BIOS patches from pinned catalogs for boards that only offer Above 4G Decoding.

## Checks behind this release

Host tests, Miri on the unsafe MMIO boundary, Clippy on the UEFI target, Playwright journeys, and
a QEMU/OVMF test that boots the injected firmware, configures the driver, confirms the S3 Save
State protocol is opened, and puts the virtual machine through an ACPI S3 suspend and resume. QEMU
has no NVIDIA GPU, so the BAR itself is proven only on hardware, as above.

# NvStrapsReBar 1.0.0 (한국어)

첫 정식 릴리스입니다. BIOS에 Resizable BAR 항목이 없는 메인보드에서 NVIDIA Turing GPU(GTX 1600,
RTX 2000)의 Resizable BAR를 켭니다. 안정판 Rust로 만든 UEFI 드라이버와, BIOS 이미지를 준비하고
드라이버 설정을 고치는 Windows 앱으로 이루어져 있습니다.

## 실제 하드웨어 확인

- MSI MAG B660 TOMAHAWK WIFI DDR5(MS-7D41, BIOS 7D41vAO)와 RTX 2060 12GB: 이 프로젝트의 주입 도구로
  만든 이미지를 MSI의 M-FLASH가 받아들였고, 드라이버가 부팅된 뒤 앱으로 설정하자 앱과 GPU-Z 모두
  BAR1 16 GiB를 보고했습니다([보고](https://github.com/115dkk/NvStrapsReBar-Tauri/issues/39)).
- 게임마다 켜기 스위치는 유지 관리자의 PC(RTX 2080 SUPER, 드라이버 616.64)에서 실제 NVIDIA
  드라이버로 확인했고, 앱이 쓴 값을 모두 되돌리는 것까지 확인했습니다.

다른 보드는 여전히 각자의 첫 시도입니다. 플래시 전에 복구 방법이 되는지 확인하세요.

첫 실제 보드 테스트를 해 주신 @lucianocerantonio2 님께 특별히 감사드립니다. 플래시와 설정을
직접 하고, 해시와 스크린샷까지 붙여 보고해 주셔서 모두가 그 결과를 믿을 수 있었습니다.

## 들어 있는 파일

- `NvStrapsReBar-windows-x64.zip`: 포터블 앱(`NvStrapsReBar.exe`)과 앱이 넣는 UEFI
  드라이버(`NvStrapsReBar.ffs`). 두 파일을 같은 폴더에 둡니다.
- `NvStrapsReBar-windows-x64-setup.exe`: 같은 두 파일을 시작 메뉴 바로가기와 함께 설치하는 설치
  파일. 바탕화면 바로가기는 고를 수 있습니다.
- `SHA256SUMS.txt`: 두 파일의 체크섬.

Windows x64와 WebView2, 그리고 UEFI 변수를 쓰기 위한 관리자 계정이 필요합니다. NVIDIA 드라이버의
게임별 설정은 Windows에만 있고 macOS에는 Turing용 NVIDIA 드라이버가 없어서, Linux와 macOS용 앱은
없습니다.

## 기능

- 네 단계로 안내하는 설치: BIOS 이미지와 원본을 담은 USB 묶음 준비, 제조사 도구로 설치, 확장
  켜기, NVIDIA 드라이버가 알려 주는 BAR 크기 확인.
- BAR 설정: 확장 켜기와 끄기, GPU별 크기와 제외, 메인보드 쪽 BAR 크기 제한, 하드웨어를 바꿀 때
  쓰는 설정 파일.
- 드라이버 설정 데이터베이스를 직접 고치는 게임마다 켜기: 게임별 스위치, 동의를 받는 모든 게임
  스위치, 바꾼 값의 기록, 드라이버를 업데이트한 뒤에도 다른 설정은 건드리지 않는 되돌리기.
- 드라이버의 안전장치: BIOS 설정이 바뀐 부팅에서는 쉬고, CMOS 리셋 뒤에는 스스로 꺼집니다.
- Above 4G Decoding만 있는 오래된 보드를 위한, 출처가 고정된 레거시 BIOS 패치.

## 이 릴리스를 뒷받침하는 검사

호스트 테스트, unsafe MMIO 경계의 Miri, UEFI 타깃 Clippy, Playwright 여정, 그리고 주입한 펌웨어를
부팅해 드라이버를 설정하고 S3 Save State 프로토콜이 열리는지 확인한 뒤 가상 머신을 ACPI S3 절전과
복귀까지 통과시키는 QEMU/OVMF 테스트. QEMU에는 NVIDIA GPU가 없으므로 BAR 자체는 위의 실제
하드웨어에서만 증명됩니다.
