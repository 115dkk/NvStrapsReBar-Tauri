NvStrapsReBar apt repository

The Linux preview of NvStrapsReBar for Debian, Ubuntu and their relatives (amd64). Add the repository once; apt then installs the app and offers each new preview with the system's other updates.

sudo install -d -m 755 /etc/apt/keyrings
curl -fsSL https://115dkk.github.io/NvStrapsReBar-Tauri/apt/nvstraps-rebar.asc | sudo tee /etc/apt/keyrings/nvstraps-rebar.asc >/dev/null
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/nvstraps-rebar.asc] https://115dkk.github.io/NvStrapsReBar-Tauri/apt preview main" | sudo tee /etc/apt/sources.list.d/nvstraps-rebar.list
sudo apt update
sudo apt install nvstraps-rebar

The repository is signed with the project's package key, fingerprint F71D B90B 8FF8 4EC4 54D4 2763 FBA1 2447 1095 0726. To check the key before you trust it:

gpg --show-keys --fingerprint /etc/apt/keyrings/nvstraps-rebar.asc

To remove the repository again, delete /etc/apt/sources.list.d/nvstraps-rebar.list and /etc/apt/keyrings/nvstraps-rebar.asc.
