NvStrapsReBar package repositories

The Linux preview of NvStrapsReBar for x86-64. Add the repository for your system once; the system's package manager then installs the app and offers each new preview with its other updates.

Both repositories are signed with the project's package key, fingerprint F71D B90B 8FF8 4EC4 54D4 2763 FBA1 2447 1095 0726. The .rpm packages carry a signature by the same key.

Debian, Ubuntu and their relatives (apt)

sudo install -d -m 755 /etc/apt/keyrings
curl -fsSL https://115dkk.github.io/NvStrapsReBar-Tauri/apt/nvstraps-rebar.asc | sudo tee /etc/apt/keyrings/nvstraps-rebar.asc >/dev/null
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/nvstraps-rebar.asc] https://115dkk.github.io/NvStrapsReBar-Tauri/apt preview main" | sudo tee /etc/apt/sources.list.d/nvstraps-rebar.list
sudo apt update
sudo apt install nvstraps-rebar

To check the key before you trust it:

gpg --show-keys --fingerprint /etc/apt/keyrings/nvstraps-rebar.asc

To remove the repository again, delete /etc/apt/sources.list.d/nvstraps-rebar.list and /etc/apt/keyrings/nvstraps-rebar.asc.

Fedora and other systems with dnf

sudo curl -fsSL -o /etc/yum.repos.d/nvstraps-rebar.repo https://115dkk.github.io/NvStrapsReBar-Tauri/rpm/nvstraps-rebar.repo
sudo dnf install nvstraps-rebar

The first time, dnf shows the key it is about to trust and asks. Compare its fingerprint with the one above before you answer yes.

To remove the repository again, delete /etc/yum.repos.d/nvstraps-rebar.repo.
